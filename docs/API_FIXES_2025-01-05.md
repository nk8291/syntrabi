# API Endpoint Fixes - January 5, 2025

## Issue Summary
Three POST endpoints in `backend/app/routes/datasets.py` were incorrectly expecting request parameters as query parameters instead of request body (JSON payload).

### Error Message
```
{
  "detail": [
    {
      "type": "missing",
      "loc": ["query", "connector_type"],
      "msg": "Field required",
      "input": null
    }
  ]
}
```

---

## Root Cause

FastAPI interprets function parameters without type annotations like `Body()`, `Query()`, etc. as **query parameters** by default when using primitive types.

### Before (Incorrect)
```python
@router.post("/connectors/test")
async def test_data_source_connection(
    connector_type: str,        # ❌ Interpreted as query parameter
    config: Dict[str, Any],     # ❌ Interpreted as query parameter
    current_user: User = Depends(get_current_user)
):
    ...
```

This expected the request URL to be:
```
POST /api/datasets/connectors/test?connector_type=postgresql&config=...
```

But the frontend was sending:
```json
POST /api/datasets/connectors/test
{
  "connector_type": "postgresql",
  "config": { ... }
}
```

---

## Solution

Change all three endpoints to accept request body using `Body(...)`:

### After (Correct)
```python
from fastapi import Body

@router.post("/connectors/test")
async def test_data_source_connection(
    request: Dict[str, Any] = Body(...),  # ✅ Accepts JSON body
    current_user: User = Depends(get_current_user)
):
    # Extract parameters from body
    connector_type = request.get("connector_type")
    config = request.get("config")

    # Validate required fields
    if not connector_type:
        raise HTTPException(status_code=400, detail="connector_type is required")
    if not config:
        raise HTTPException(status_code=400, detail="config is required")

    # Continue with logic...
```

## Deployment Notes

### Backend Restart Required
If the backend server is **not** running with auto-reload (`--reload` flag), you need to restart it:

```bash
# Windows
# Find the process
netstat -ano | findstr :8000

# Kill the process (replace PID with actual process ID)
taskkill /PID <PID> /F

# Restart backend
cd backend
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### Docker Compose
If running with Docker Compose:
```bash
docker-compose restart backend
```
